# Dev log

I am a chemical engineer at **PLAPIQUI (UNS–CONICET)** in Argentina, working on particle
technology and droplet physics. I teach, and I build the software that work needs: image
analysis, numerical models, instrument parsers, and the desktop tools that wrap them.

This is where I write it down — the physics and the numerics, the engineering underneath,
what pair-programming with an AI assistant is actually like on a real codebase, and how any
of it survives contact with a classroom.
